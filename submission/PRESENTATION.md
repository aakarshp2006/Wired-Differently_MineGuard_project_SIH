# MineGuard – Final Presentation

**Team:** Wired Differently
**Problem Statement ID:** SIH26007
**Problem Statement Title:** Safe and Efficient Operation of Mine Vehicles in Fog and Low-Visibility Conditions in Open Cast Iron Ore Mines

## Presentation file

The final SIH presentation is included directly in this repository (file size ≈ 2.75 MB):

📄 [`SIH_Wired_Differently_2026.pdf`](./SIH_Wired_Differently_2026.pdf)

The presentation covers:
- Title page (problem statement, team details)
- Idea title and how the solution works (SENSE → PERCEIVE → ASSESS → ACT)
- Technical approach — system architecture, technology stack, and dashboard wireframes
- Feasibility and viability — technical feasibility, risks, and mitigation strategies
- Impact and benefits — safety, productivity, fleet operations, and economic/environmental impact
- Research and references

## Note on naming

The presentation refers to the idea as **"SmartFog"** in places — this is the same project as **MineGuard**, the name used throughout this repository's code and documentation.
